# 1. Basic Structure and Frames

Beamer is a LaTeX document class for creating presentations.

## Document class
```latex
\documentclass{beamer}
```

## Frame
A frame represents an individual slide:
```latex
\begin{frame}{Slide Title}
  Content of the slide.
\end{frame}
```

## Bullet points
Use the `itemize` environment:
```latex
\begin{itemize}
  \item First point
  \item Second point
\end{itemize}
```
