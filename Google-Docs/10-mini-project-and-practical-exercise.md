# 10. Mini Project and Practical Exercise Using Google Docs

## 10.1 Objective

The objective of this mini project is to create a well-structured academic report using Google Docs.

The exercise demonstrates document creation, formatting, collaboration, inserting elements, citations, and exporting.

## 10.2 Project: Creating an Academic Report

**Topic:** Applications of Artificial Intelligence in Education

Create a report containing the following sections:

1. Title Page
2. Introduction
3. Applications of Artificial Intelligence
4. Advantages and Challenges
5. Conclusion
6. References

## 10.3 Step 1: Create a Document

1. Open Google Docs.
2. Create a blank document.
3. Give the document an appropriate title.
4. Add the report title and author details.
5. Organize the document using headings.

## 10.4 Step 2: Apply Formatting

- Use Heading 1 for major sections.
- Use Heading 2 for subsections.
- Select an appropriate font and font size.
- Apply bold and italic formatting where required.
- Adjust paragraph alignment and spacing.
- Maintain consistent formatting throughout the report.

## 10.5 Step 3: Insert Tables and Images

- Insert a table comparing different applications of AI in education.
- Add a relevant image or illustration.
- Include a suitable caption or description.
- Adjust the size and alignment of inserted elements.

## 10.6 Step 4: Collaborate with Others

1. Click the Share button.
2. Add a classmate using their email address.
3. Assign Editor or Commenter access.
4. Ask the classmate to review the report.
5. Use comments and suggestions to improve the content.

## 10.7 Step 5: Use Version History

1. Open File → Version history.
2. Select See version history.
3. Review previous versions of the report.
4. Observe how changes are recorded.
5. Restore an earlier version if required.

## 10.8 Step 6: Add Citations and References

- Open Tools → Citations.
- Select an appropriate citation style.
- Add source details.
- Insert citations in the report.
- Generate a bibliography or works cited section.

## 10.9 Step 7: Export the Final Report

1. Review the complete document.
2. Check formatting, spelling, and references.
3. Select File → Download.
4. Export the document as PDF.
5. Open the downloaded file and verify its appearance.

## 10.10 Learning Outcomes

After completing this exercise, students should be able to:

- Create and organize documents in Google Docs.
- Apply formatting and styles.
- Insert tables and images.
- Collaborate using sharing permissions.
- Review changes through comments and version history.
- Add citations and references.
- Export documents into different formats.

## 10.11 Conclusion

This practical exercise demonstrates how Google Docs can be used to prepare academic and technical documents. It combines formatting, collaboration, reviewing, referencing, and publishing features in a single workflow.
