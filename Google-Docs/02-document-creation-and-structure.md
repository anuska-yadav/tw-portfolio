# 2. Document Creation and Structure

## 2.1 Creating a New Document

Google Docs provides a simple interface for creating and editing documents.

A new document can be created using the following steps:

1. Open [Google Docs](https://docs.google.com/).
2. Sign in using a Google account.
3. Click the Blank document option to create a new document.
4. Enter a suitable title for the document.
5. Start writing and editing the content.

Documents are automatically saved to Google Drive while working.

## 2.2 Using Templates

Google Docs provides ready-made templates for different types of documents.

Some commonly available templates include:

- Reports
- Meeting notes
- Project proposals
- Resumes
- Letters
- Academic documents

Templates provide a predefined layout and formatting, reducing the time required to design a document from scratch.

## 2.3 Organizing Document Content

A well-structured document is easier to read, understand, and maintain.

Google Docs provides several tools for organizing content:

- Use headings to divide a document into sections.
- Use paragraphs to explain individual ideas.
- Use numbered lists for sequential instructions.
- Use bullet points for unordered information.
- Use tables to present structured data.
- Use page breaks to separate major sections.

## 2.4 Paragraph Styles and Heading Hierarchy

Google Docs provides predefined paragraph styles to maintain consistent formatting throughout a document.

Common paragraph styles include:

| Style | Purpose |
|---|---|
| Title | Main document title |
| Subtitle | Additional information below the title |
| Heading 1 | Main sections |
| Heading 2 | Subsections |
| Heading 3 | Smaller subsections |
| Normal Text | Regular paragraph content |

Paragraph styles can be applied using the style dropdown in the toolbar.

Using heading styles instead of manually changing font sizes helps maintain a consistent document structure.

## 2.5 Creating a Table of Contents

Google Docs can automatically generate a table of contents using the heading styles applied throughout the document.

Steps:

1. Apply Heading 1, Heading 2, and other appropriate styles to section titles.
2. Place the cursor where the table of contents should appear.
3. Open the Insert menu.
4. Select Page elements and then Table of contents.
5. Choose the desired table of contents format.

The table of contents can be updated when headings or page positions change.

## 2.6 Inserting Page Breaks

Page breaks help separate different sections of a document.

Steps:

1. Place the cursor at the position where a new page should begin.
2. Open the Insert menu.
3. Select Break and then Page break.

A page break moves the content following the cursor to the next page.

## 2.7 Best Practices for Document Structure

- Use meaningful document titles.
- Maintain a logical heading hierarchy.
- Apply paragraph styles consistently.
- Divide long documents into smaller sections.
- Use lists and tables wherever appropriate.
- Include a table of contents in lengthy documents.
- Avoid unnecessary formatting and excessive styling.

## 2.8 Conclusion

Proper document creation and organization improve readability and make documents easier to maintain. Google Docs provides templates, paragraph styles, headings, and automatic tables of contents to help users create structured professional documents.
