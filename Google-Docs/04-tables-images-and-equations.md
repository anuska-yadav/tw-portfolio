# 4. Tables, Images, and Equations in Google Docs

## 4.1 Introduction

Google Docs allows users to insert tables, images, and mathematical equations into documents.

These elements make technical documents more informative, organized, and visually understandable.

## 4.2 Inserting Tables

Tables are used to organize information into rows and columns.

Steps to insert a table:

1. Open the Insert menu.
2. Select Table.
3. Choose the required number of rows and columns from the grid.
4. Enter the required information into the cells.

### Example

| Student | Subject | Marks |
|---|---|---:|
| Rahul | Mathematics | 85 |
| Priya | Physics | 90 |
| Aman | Computer Science | 88 |

### Editing Tables

Google Docs provides several table editing options:

- Insert or delete rows and columns.
- Merge or split cells.
- Adjust column width and row height.
- Change cell background color.
- Modify border color and thickness.
- Align text within cells.

These options are useful for presenting structured information.

## 4.3 Inserting Images

Images help explain concepts and improve the visual presentation of documents.

Steps to insert an image:

1. Open the Insert menu.
2. Select Image.
3. Choose the image source, such as uploading from a computer or Google Drive.
4. Select the required image.
5. Adjust its size and position.

### Image Formatting Options

Google Docs provides different image formatting options:

- **In line with text:** Treats the image like a text character.
- **Wrap text:** Allows text to flow around the image.
- **Break text:** Places text above and below the image.
- **Behind text:** Places the image behind the text.
- **In front of text:** Places the image over the text.

Users can also crop, resize, rotate, and reposition images.

## 4.4 Inserting Drawings and Diagrams

Google Docs supports drawings and diagrams through its drawing tools.

Steps:

1. Open the Insert menu.
2. Select Drawing and then New.
3. Use shapes, lines, arrows, and text boxes.
4. Arrange the elements to create a diagram.
5. Save and close the drawing.

Drawings can be used for flowcharts, block diagrams, and simple illustrations.

## 4.5 Inserting Mathematical Equations

Google Docs provides an equation editor for writing mathematical expressions.

Steps:

1. Open the Insert menu.
2. Select Equation.
3. Use the equation toolbar to insert mathematical symbols and structures.
4. Enter the required mathematical expression.

The equation editor supports symbols such as:

- Fractions
- Square roots
- Summation symbols
- Integrals
- Greek letters
- Mathematical operators

### Example Equations

Quadratic formula:

\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]

Pythagorean theorem:

\[
a^2 + b^2 = c^2
\]

Note: The equations above illustrate mathematical notation; in Google Docs, use the built-in equation editor to create them.

## 4.6 Adding Captions and Explanations

Captions provide descriptions of tables, images, and diagrams.

For example:

- Table 1: Comparison of Programming Languages.
- Figure 1: Basic Computer Architecture.

Captions help readers understand the purpose of visual elements and make technical documents easier to navigate.

## 4.7 Best Practices

- Use tables for structured information rather than long paragraphs.
- Choose clear and relevant images.
- Maintain appropriate image sizes and alignment.
- Avoid inserting unnecessarily large images.
- Use diagrams to explain complex processes.
- Keep mathematical equations properly formatted.
- Provide captions and explanations for important visual elements.

## 4.8 Conclusion

Tables, images, drawings, and equations improve the clarity and presentation of technical documents. Google Docs provides built-in tools for inserting and editing these elements, making it useful for academic and professional documentation.
