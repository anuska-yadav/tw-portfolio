# Git and GitHub Practical Work — Workflow matching your 9 chapters

1. Introduction: understand version control and local/remote repositories.
2. Installation and configuration: run `git --version` and configure your name/email.
3. Basic commands: initialize, clone, status, add, commit, log.
4. Inspecting changes: practise `status`, `diff`, staged diff and log.
5. Branching and merging: create a feature branch, commit, switch and merge.
6. Remote repositories: create an empty GitHub repo, add `origin`, push and pull.
7. Undoing changes: practise `restore`, `restore --staged`, and reset only in this disposable practice repo.
8. Collaboration: simulate fork/clone/upstream workflow; use a feature branch and pull request if working with a partner.
9. Troubleshooting: use the troubleshooting sheet.

Use your own GitHub URL and your own Git identity. Never put passwords, access tokens, or private keys in this folder.
