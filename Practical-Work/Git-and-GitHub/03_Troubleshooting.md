# Git troubleshooting quick sheet
- Git not found: install Git and reopen the terminal.
- Author identity unknown: set `user.name` and `user.email`.
- Nothing to commit: save changes and inspect `git status`.
- Branch name differs: inspect `git branch`; the default may be `master` rather than `main`.
- Push rejected: fetch/pull and resolve conflicts before pushing.
- Authentication failure: use GitHub's supported sign-in/token/SSH process; never save credentials in your public repository.
