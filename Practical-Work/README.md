# Technical Writing Portfolio — Practical Work Pack

This package contains practical files for all five topics in the portfolio. The order follows the documentation folders and their chapter sequence.

## Recommended order
1. Beamer
2. LaTeX
3. Doxygen
4. Git and GitHub
5. Google Docs

## What file types are included?
- Beamer and LaTeX: `.tex` source files and compiled `.pdf` outputs.
- Doxygen: C++ source, Doxyfile, and step-by-step generation instructions. Doxygen HTML is generated on your computer after installing Doxygen.
- Git and GitHub: command practice sheets, task instructions, and sample files. Git actions must be performed in your local terminal and GitHub account.
- Google Docs: report source content, an editable `.docx` starter, a sample `.pdf`, and a practical checklist. The Google Docs features must be demonstrated in Google Docs itself.

## How to place these files
Extract this package. Copy each topic folder into the matching folder inside your repository's `Practical-Work/` directory. If a destination already contains files, compare and replace duplicates rather than creating nested duplicate folders.

## Important
The PDFs are sample compiled outputs. Keep the matching `.tex` files because they show the editable LaTeX source. Replace `Student Name` in source files where it appears. For Google Docs, upload/open the DOCX in Google Docs and complete the browser-based steps yourself. Do not include private email addresses, access tokens, or passwords in screenshots.
