# Google Docs Practical Work — Workflow matching your 10 chapters

Google Docs is a live browser application, so its practical must be completed in your Google account. This package gives you a report starter and a precise workflow.

1. Introduction: open Google Docs and identify its key features.
2. Document creation and structure: create a report, apply heading styles, insert a table of contents and page breaks.
3. Formatting and editing: apply text/paragraph formatting, lists, find/replace and page setup.
4. Tables, images and equations: insert and format a table, image, drawing/diagram and equation.
5. Collaboration and sharing: share with an appropriate collaborator, demonstrate Viewer/Commenter/Editor roles, comments and Suggesting mode.
6. Version history and review: name a version, inspect history, and demonstrate restore only if safe.
7. Citations and references: add actual sources you consulted using the citation tool and create a bibliography.
8. Exporting and publishing: download as PDF and DOCX; demonstrate print/publish only if appropriate.
9. Security, integrations and best practices: review permissions, avoid public access to private information, and discuss integrations.
10. Mini-project: complete the academic report using the starter content.

The DOCX and PDF are starter/sample files. Upload the DOCX to Google Docs, then complete the Google Docs-specific features there. Do not share a live document publicly just to take a screenshot.
