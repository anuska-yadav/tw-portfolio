# LaTeX Practical Work

The practicals are ordered to match the eight chapters in your LaTeX documentation. The introductory document also demonstrates the document structure; the remaining examples map to text formatting, mathematics, tables, figures, colours/picture environment, and environments. An extra file covers arrays, matrices, and lists mentioned in your course material.

## Workflow
1. Open each `.tex` file in Overleaf (or compile locally with pdfLaTeX).
2. Compile and inspect the matching PDF.
3. For `05_Figures_and_Images.tex`, keep `sample-image.png` in the same Overleaf project.
4. Compare the result with the corresponding documentation chapter.
